unifont.bin is NOT source code of hipda-kindle: it is a generated data file
(HUF1 format: sorted codepoint + 16x16 1bpp bitmap records), kept as a
separate on-device asset so the rest of the program has no font-library
dependency. If you redistribute this package, include this notice and comply
with the Unifont license.

Regenerate with:
  python tools/gen_font.py
