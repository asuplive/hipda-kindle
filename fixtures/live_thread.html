Android 论坛客户端 HiPDA·NG [v5.0.05]

本帖最后由 绿皮怪兽 于 2023-2-23 09:16 编辑

最近有点时间，老项目找出来，做了点小修补，再发个版本，稳定后估计长时间不会再调整了。

================================
反馈问题请按照下面几点要求：
================================
* 问题请反馈到本帖，“设置 > 客户端发布帖”。便于信息共享，请不要另开新帖，也不要PM。

具体步骤：
》》》 如程序崩溃，请到“设置-其它-应用错误日志”，将内容粘帖回复至本帖。
》》》 如其它错误，请描述错误出现时的操作步骤，以及相关的帖子，可以提供截图。

================================
HiPDA·NG 版 是HiPDA论坛的非官方客户端。

首先必需感谢 jejer 开源了他的简洁客户端
原帖地址 https://www.hi-pda.com/forum/viewthread.php?tid=1408844

HiPDA·NG 是使用MD风格的版本，即master分支，为目前主要维护版本。
怪兽版 则是原版风格的版本，即classic分支，已经停止功能更新，仅修复重大问题。
================================


================================
使用注意事项
================================
1. 长按帖子标题，直达帖子最新回复，某些跳转到指定楼层的场合除外。
2. 双击帖子内容，弹出页面跳转对话框，同时显示完整帖子标题，标题文字可以选取并复制。
3. 长按楼层，点击弹出菜单中“文字选择”，本楼层文字将变为可以选择状态，点击桔红色"X"可以关闭。
4. 查看帖子最后一页，底部的"~END~"可以点击，以刷新此帖最新回复。
5. 快速回复时，长按回复按钮可以转到正常回复模式，以上传图片或者恢复之前输入的内容(右上角菜单)。
6. 查看帖子内容时，触摸时会有一个背景阴影效果，可以在“设置-用户界面-列表点击效果”关闭。

================================
关于删除图片：
================================
每个图片上传会对应一个数字id，如 12345678，帖子内容中 attachimg 标签结合数字id即表示该图片的位置。
只要删除帖子内容中图片对应的 attachimg 标签，在点击发送时，选择 “丢弃图片” 就会删除这些图片。


================================
黑名单同步功能：
================================
论坛自身具备黑名单功能，但是只屏蔽短消息，不屏蔽黑名单用户的帖子。
功能入口：https://www.hi-pda.com/forum/pm.php?action=viewblack
另外用户 fqxufo 还开发了chrome插件，能与论坛黑名单同步，需要的可以安装。
https://www.hi-pda.com/forum/vie ... 05417&extra=&page=1
客户端 4.3 版开始，使用论坛的黑名单功能存储黑名单数据，屏蔽短消息同时也屏蔽黑名单用户的帖子。
因为数据存储在论坛，重装客户端可以自动恢复黑名单，或者与其它同样同步黑名单机制的客户端保持同步。
黑名单每天自动同步一次，进入 设置 > 黑名单 功能时也会自动与论坛黑名单同步。
注意首次使用，请先在“设置 > 论坛选项 > 黑名单”上传旧版本黑名单数据。


================================
接收通知的后台任务：
================================
需要允许自启，检查通知间隔为15分钟-20分钟左右。观察“设置-消息通知-上次检查”的时间持续更新的话，说明后台任务生效。

================================
关于捐助
================================
捐助体验完毕，现在开始不再接受捐助。
非常感谢各位参与捐助的用户，捐助名单在“设置 > 关于 > 捐助名单”中。

v5.0.05
+ 缓存DNS解析，可能会改善部分情况下加载缓慢的问题。
+ 改进投票显示。
+ 移除老的图片选择和拍照上传方式。

v5.0.04
+ 使用系统图片选择界面，原上传图片方式移动至右上角菜单中。
+ 改进图片压缩处理方式，减少不必要的压缩。

v5.0.03
X 修复一些帖子不能显示的问题。

v5.0.02
X 取消隐藏客户端小尾巴功能，可能导致某些帖子内容不能显示。

v5.0.01
+ 多帐号支持。
+ 帖子浏览改进为连续翻页模式。
+ 浅色深色系统主题切换支持。
+ 统一浅色主题主色调与状态栏颜色。
+ 主题和字体设置移至左侧菜单。
+ 字体使用导入方式，支持导入多个字体。
+ 图片查看界面和动画改进。
+ 支持回复投票帖(不支持发起投票帖)。
+ 支持SDK30,最大程度减少权限使用。
+ 自动保存应用崩溃错误日志(设置-其它)。
